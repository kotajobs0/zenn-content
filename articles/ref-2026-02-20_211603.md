# 【Wiki】非同期処理 (Java/C# 実装リファレンス)

このリファレンスでは、JavaとC#における非同期処理の実装方法について解説します。新人エンジニアが「そのまま実行できる」コード例とともに、より深い理解を得るためのメモリ効率やスレッドセーフなどのプロフェッショナルな視点も提供します。

## 1. はじめに

非同期処理は、時間のかかる処理をバックグラウンドで実行し、UIの応答性を維持したり、システムの処理能力を向上させるために不可欠な技術です。

### 1.1. なぜ非同期処理が必要なのか？

*   **UIの応答性**: 重い処理をメインスレッドで実行するとUIがフリーズしてしまいます。非同期処理によって、UIをブロックせずに処理を実行できます。
*   **処理能力の向上**: 複数の処理を並行して実行することで、全体の処理時間を短縮できます。
*   **スケーラビリティ**: リクエストを効率的に処理し、システム全体の負荷を分散できます。

## 2. Javaでの非同期処理

### 2.1. `ExecutorService` を利用した非同期処理

`ExecutorService` は、スレッドプールの管理とタスクの実行を抽象化するためのインターフェースです。

**即実行可能なコード (Ready-to-Run)**:

```java
import java.util.concurrent.ExecutorService;
import java.util.concurrent.Executors;
import java.util.concurrent.Future;
import java.util.concurrent.Callable;
import java.util.concurrent.ExecutionException;

public class AsyncExample {

    public static void main(String[] args) {
        // スレッドプールを作成 (固定スレッド数)
        ExecutorService executor = Executors.newFixedThreadPool(2);

        // Callableインターフェースを実装したタスク
        Callable<String> task = () -> {
            System.out.println("Task started by: " + Thread.currentThread().getName());
            Thread.sleep(2000); // 2秒間の処理をシミュレート
            return "Task completed!";
        };

        // タスクをExecutorServiceにsubmit
        Future<String> future = executor.submit(task);

        System.out.println("Main thread continues to execute...");

        try {
            // 結果を取得 (非同期的に実行されるタスクの完了を待つ)
            String result = future.get();
            System.out.println("Result: " + result);
        } catch (InterruptedException | ExecutionException e) {
            e.printStackTrace();
        } finally {
            // ExecutorServiceをシャットダウン
            executor.shutdown();
        }
    }
}
```

**解説**:

*   `ExecutorService`: スレッドプールを管理し、タスクの実行を制御します。`Executors` クラスを使って、固定スレッド数、キャッシュスレッドプールなど、様々な種類の `ExecutorService` を作成できます。
*   `Callable`: `Runnable` インターフェースに似ていますが、戻り値を返すことができます。`Future` オブジェクトを使って、非同期タスクの結果を取得したり、タスクの実行をキャンセルしたりできます。
*   `Future.get()`: タスクの結果を取得するために、タスクの完了を待ちます。`InterruptedException` と `ExecutionException` は、タスクの実行中にエラーが発生した場合にスローされます。
*   `executor.shutdown()`: ExecutorServiceを安全にシャットダウンします。新しいタスクの受付を停止し、実行中のタスクが完了するのを待ちます。

**バージョン・アップデート情報**:

*   **Java 5**: `ExecutorService` が導入されました。
*   **Java 8**: Lambda式が導入され、`Callable` インターフェースの実装が簡潔になりました。

**プロフェッショナルな視点**:

*   **スレッドプールの選択**: スレッドプールの種類（`newFixedThreadPool`, `newCachedThreadPool`, `newScheduledThreadPool` など）は、アプリケーションの要件に合わせて慎重に選択する必要があります。例えば、CPUバウンドなタスクが多い場合は、固定スレッドプールが適しています。IOバウンドなタスクが多い場合は、キャッシュスレッドプールが適しています。
*   **例外処理**: 非同期タスク内で発生した例外は、メインスレッドに伝播されません。`Future.get()` で `ExecutionException` をキャッチして、例外を処理する必要があります。
*   **リソース管理**: スレッドプールは、システムリソースを消費します。適切なサイズのスレッドプールを作成し、不要になったらシャットダウンすることが重要です。

### 2.2. `CompletableFuture` を利用した非同期処理 (Java 8以降)

`CompletableFuture` は、非同期処理の結果をより柔軟に操作するためのAPIを提供します。

**即実行可能なコード (Ready-to-Run)**:

```java
import java.util.concurrent.CompletableFuture;
import java.util.concurrent.ExecutionException;
import java.util.concurrent.TimeUnit;
import java.util.concurrent.TimeoutException;

public class CompletableFutureExample {

    public static void main(String[] args) {
        CompletableFuture<String> future = CompletableFuture.supplyAsync(() -> {
            System.out.println("Task started by: " + Thread.currentThread().getName());
            try {
                TimeUnit.SECONDS.sleep(2); // 2秒間の処理をシミュレート
            } catch (InterruptedException e) {
                Thread.currentThread().interrupt();
                return "Task interrupted!";
            }
            return "Task completed!";
        });

        System.out.println("Main thread continues to execute...");

        try {
            // 結果を取得 (タイムアウト付き)
            String result = future.get(3, TimeUnit.SECONDS); // 3秒以内に結果を取得
            System.out.println("Result: " + result);
        } catch (InterruptedException | ExecutionException | TimeoutException e) {
            e.printStackTrace();
        }
    }
}
```

**解説**:

*   `CompletableFuture.supplyAsync()`: 非同期的に値を生成するタスクを実行します。
*   `future.get(timeout, unit)`: 結果を取得する際にタイムアウトを設定できます。
*   `CompletableFuture` には、`thenApply`, `thenAccept`, `thenCompose`, `thenCombine` など、様々なメソッドが用意されており、非同期処理の結果を連鎖的に処理したり、複数の非同期処理を組み合わせたりできます。

**バージョン・アップデート情報**:

*   **Java 8**: `CompletableFuture` が導入されました。

**プロフェッショナルな視点**:

*   **エラーハンドリング**: `exceptionally`, `handle`, `whenComplete` などのメソッドを使って、非同期処理中に発生した例外を適切に処理できます。
*   **処理の組み合わせ**: `thenCompose` を使うと、前のタスクの結果を次のタスクに渡し、非同期処理を連鎖的に実行できます。`thenCombine` を使うと、複数の非同期タスクの結果を組み合わせて、新しい結果を生成できます。
*   **キャンセル**: `future.cancel()` を使うと、タスクの実行をキャンセルできます。

## 3. C#での非同期処理

### 3.1. `async` と `await` を利用した非同期処理

C# では、`async` と `await` キーワードを使って、非同期処理をより簡単に記述できます。

**即実行可能なコード (Ready-to-Run)**:

```csharp
using System;
using System.Threading.Tasks;

public class AsyncExample
{
    public static async Task Main(string[] args)
    {
        Console.WriteLine("Main thread continues to execute...");

        // 非同期メソッドの呼び出し
        string result = await DoSomethingAsync();

        Console.WriteLine("Result: " + result);
    }

    // 非同期メソッド
    public static async Task<string> DoSomethingAsync()
    {
        Console.WriteLine("Task started by: " + System.Threading.Thread.CurrentThread.ManagedThreadId);
        await Task.Delay(2000); // 2秒間の処理をシミュレート
        return "Task completed!";
    }
}
```

**解説**:

*   `async`: メソッドが非同期処理を含むことを示します。`async` キーワードが付いたメソッドは、`await` キーワードを使用できます。
*   `await`: 非同期タスクの完了を待ちます。`await` キーワードが付いた式は、タスクが完了するまでメソッドの実行を一時停止します。タスクが完了すると、メソッドの実行が再開されます。
*   `Task.Delay()`: 指定された時間だけ待機するタスクを作成します。
*   `Task<T>`: 非同期処理の結果を返すタスクを表します。

**バージョン・アップデート情報**:

*   **C# 5**: `async` と `await` キーワードが導入されました。

**プロフェッショナルな視点**:

*   **SynchronizationContext**: UIスレッドで `await` を使用すると、処理が完了した後にUIスレッドに処理が戻ります。これは、UIを更新するために重要です。
*   **ConfigureAwait(false)**: `await` の後にUIスレッドに戻る必要がない場合は、`ConfigureAwait(false)` を使用することで、パフォーマンスを向上させることができます。
*   **例外処理**: `try-catch` ブロックを使用して、非同期処理中に発生した例外を処理できます。
*   **Deadlock**: `async void` メソッドは避けるべきです。`async void` メソッドは例外をキャッチしにくく、デッドロックを引き起こす可能性があります。

### 3.2. `Task.Run` を利用した非同期処理

`Task.Run` は、スレッドプールでタスクを実行するための便利なメソッドです。

**即実行可能なコード (Ready-to-Run)**:

```csharp
using System;
using System.Threading.Tasks;

public class AsyncExample
{
    public static async Task Main(string[] args)
    {
        Console.WriteLine("Main thread continues to execute...");

        // Task.Runを使ってタスクをスレッドプールで実行
        string result = await Task.Run(() => DoSomething());

        Console.WriteLine("Result: " + result);
    }

    public static string DoSomething()
    {
        Console.WriteLine("Task started by: " + System.Threading.Thread.CurrentThread.ManagedThreadId);
        System.Threading.Thread.Sleep(2000); // 2秒間の処理をシミュレート
        return "Task completed!";
    }
}
```

**解説**:

*   `Task.Run()`: 指定されたデリゲートをスレッドプールで非同期的に実行します。
*   `DoSomething()` メソッドは、`async` キーワードを必要としません。

**プロフェッショナルな視点**:

*   **CPUバウンドな処理**: `Task.Run` は、CPUバウンドな処理に適しています。IOバウンドな処理には、`async` と `await` を使用する方が適しています。
*   **SynchronizationContext**: `Task.Run` で実行されたタスクは、既定のSynchronizationContextを持ちません。UIスレッドで実行する必要がある場合は、SynchronizationContextを明示的に設定する必要があります。
