**2. 原因の特定方法**

NullPointerExceptionは、`null`値のオブジェクトに対してメソッドを呼び出したり、フィールドにアクセスしようとした場合に発生します。以下の手順で原因を特定します。

原因が特定できたら、以下の解決策を検討します。

*   **`null`チェック:** エラーが発生する前に、変数が`null`でないことを確認します。`if`文を使って`null`チェックを行うのが一般的です。
*   **初期化:** オブジェクトを使用する前に、必ず初期化します。コンストラクタや初期化メソッドを使用して、オブジェクトに値を設定します。
*   **デフォルト値の設定:** 変数が`null`になる可能性がある場合、デフォルト値を設定します。これにより、`null`PointerExceptionを回避できます。
*   **Optionalクラスの利用 (Java):** `Optional`クラスは、値が存在しない可能性のある変数を安全に扱うためのものです。`null`チェックを明示的に行う必要がなくなり、コードがより安全で読みやすくなります。
*   **Null許容型 (C#):** C#では、`?`演算子を使ってNull許容型を定義できます。これにより、`null`を代入できる変数を明示的に宣言でき、コンパイラが`null`参照の可能性をチェックしてくれます。
*   **早期リターン:** メソッドの先頭で、`null`の場合に早期にリターンするようにします。
*   **防御的プログラミング:** 予期せぬ`null`値を考慮し、常に安全なコードを作成します。

*   メソッドの引数や戻り値が`null`でないことを期待できるか？

*   ループ処理で、配列やリストの要素にアクセスする際に、インデックスが範囲外になっていないか？

## Java vs C# 実装比較：NullPointerException対策の最新機能

ここでは、JavaとC#でNullPointerExceptionを回避するための最新機能を見ていきましょう。

### Java (Java 21): Switch文のパターンマッチングの進化

Java 21では、Switch文のパターンマッチングがさらに進化しました。これにより、`null`チェックと型チェックを同時に行うことができ、コードがより簡潔になります。

```java
// Java 21以降
String str = ...; // nullの可能性あり

String result = switch (str) {
    case null -> "文字列がnullです";
    case String s -> "文字列の長さは" + s.length() + "です";
};

System.out.println(result);
```

この例では、`str`が`null`の場合と、`String`オブジェクトの場合で異なる処理を行っています。`case null`を使うことで、明示的な`null`チェックが不要になり、コードがすっきりします。

### C# (C# 12): Null許容参照型とIsNullOrEmpty

C#では、Null許容参照型（Nullable Reference Types）が導入され、コンパイラが`null`参照の可能性をチェックしてくれるようになりました。また、`string.IsNullOrEmpty()`や`string.IsNullOrWhiteSpace()`といった便利なメソッドも用意されています。

```csharp
// C#
string? str = null; // Null許容参照型

if (string.IsNullOrEmpty(str))
{
    Console.WriteLine("文字列がnullまたは空です");
}
else
{
    Console.WriteLine($"文字列の長さは{str.Length}です");
}
```

`string? str`のように、型名の後に`?`をつけることで、その変数が`null`を許容することを明示的に示します。コンパイラは、`null`許容参照型の変数に対して`null`チェックを行わずにアクセスしようとすると警告を表示してくれるため、未然にNullPointerExceptionを防ぐことができます。

また、`string.IsNullOrEmpty(str)`は、`str`が`null`または空文字列("")の場合に`true`を返します。`IsNullOrWhiteSpace`は、`null`、空文字列、または空白文字のみからなる文字列の場合に`true`を返します。これらのメソッドを使うことで、簡潔に`null`チェックを行うことができます。
