## はじめに

こんにちは。ITフィールドセールスをしている長井洸太です。

「AIを業務に入れたいけど、うちの業務は複雑だから無理だと思う」

最近、こういう声をよく聞きます。エンジニアの方からも、経営者の方からも。

でも実際に業務を整理してみると、気づくことがあります。

**「複雑」に見えていた業務の多くは、本当に複雑なのではなく、"整理されていない"だけだった。**

今日はこの話を、ClaudeとのAI対話例を交えながら書きます。

## AIが苦手なのは「曖昧な指示」

まず前提として、AIが苦手なのは複雑な作業ではありません。

**曖昧な指示**です。

たとえばこの2つの指示を比べてみてください。

```
❌ 「この件、いい感じにまとめといて」

✅ 「以下の議事録から、決定事項・アクションアイテム・担当者・期限を
   Markdown形式の表にまとめてください。
   決定事項が不明な場合は"要確認"と記載してください。」
```

前者はベテランの人間でも迷います。後者は条件が明確なので、AIが高い精度で処理できます。

つまり「AIに任せられるか」は業務の複雑さではなく、**業務を言語化できているか**で決まります。

---

## AIとの対話で業務を言語化してみた

私が実際にClaudeとこんな対話をしました。

---

**私：**
```
毎週月曜日にやっている業務があるのですが、AIに任せられるか確認したいです。
具体的な手順を一緒に整理してもらえますか？
```

**Claude：**
```
もちろんです。以下の4つを教えてください。

1. この業務の「完了状態」はどんな状態ですか？
2. インプットは何ですか？（メール・ファイル・Webサイトなど）
3. アウトプットは何ですか？（メール送信・ファイル作成・入力など）
4. 判断が必要な場面はありますか？あればどんな判断ですか？
```

---

この4つの問いを受けて、私は「なんとなくやっていた業務」を初めてきちんと言語化できました。

```
1. 完了状態：週次レポートをSlackの#weekly-reportチャンネルに送信した状態
2. インプット：前週のGoogleアナリティクスのCSV + 前回のレポートMD
3. アウトプット：今週のレポートMD（先週比・コメント付き）
4. 判断：数値が前週比±20%以上の項目には「要注目」フラグを付ける
```

こうして整理すると、**この業務の80%はPythonスクリプト＋Claude APIで自動化できる**ことがわかりました。

---

## 実際のコード例（Python × Claude API）

```python
import anthropic
import pandas as pd
from pathlib import Path

client = anthropic.Anthropic(api_key="your_api_key")

def generate_weekly_report(csv_path: str, prev_report_path: str) -> str:
    df = pd.read_csv(csv_path)
    prev_report = Path(prev_report_path).read_text(encoding="utf-8")

    prompt = f"""
以下のGoogleアナリティクスデータをもとに、週次レポートを作成してください。

【今週のデータ】
{df.to_markdown()}

【前回のレポート】
{prev_report}

【ルール】
- 前週比±20%以上の項目には「⚠️ 要注目」を付ける
- Markdown形式で出力する
- コメントは箇条書きで3点以内にまとめる
"""

    response = client.messages.create(
        model="claude-sonnet-4-6",
        max_tokens=1500,
        messages=[{"role": "user", "content": prompt}]
    )
    return response.content[0].text

# 実行
report = generate_weekly_report(
    csv_path="data/analytics_2026-06-25.csv",
    prev_report_path="reports/2026-06-18_weekly.md"
)

Path("reports/2026-06-25_weekly.md").write_text(report, encoding="utf-8")
print("✅ レポート生成完了")
```

## 「業務の言語化」に使えるAI対話フレーム

AIに任せたい業務があれば、まずClaudeにこう聞いてみてください。

```
「以下の業務をAIで自動化できるか教えてください。
また、自動化するために必要な情報を質問形式で整理してください。

【業務内容】
（業務の概要をざっくり書く）
」
```

Claudeが不足している情報を聞き返してくれます。それに答えていくことで、**自然と業務が言語化されます。**

## 若手エンジニアへのメッセージ

業務設計の言語化は、AIを使うためだけでなく、チームメンバーへの引き継ぎや、コードのコメントを書く力にも直結します。

「何をするか」を明確に言語化できる人は、プログラムを書くときも仕様が明確になり、バグが減ります。

AIとの対話は、その練習の場としても優れています。

**「AIに任せられない」と感じる業務があれば、まずAIと一緒に整理するところから始めてみてください。**
