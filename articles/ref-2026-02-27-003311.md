# 【Wiki】非同期処理 (Java/C# 実装リファレンス)

このWikiでは、JavaとC#における非同期処理の実装方法について、すぐに実行できるコード例とプロフェッショナルな視点での解説を提供します。

## 1. なぜ非同期処理が必要なのか？

UIのフリーズを防ぎ、バックグラウンドで重い処理を実行することで、アプリケーションの応答性を向上させるために非同期処理は不可欠です。特に、ネットワーク通信、ファイルI/O、データベースアクセスなど、時間がかかる処理を非同期で行うことで、ユーザーエクスペリエンスを大幅に改善できます。

## 2. Javaにおける非同期処理

### 2.1. `ExecutorService`と`Future`

`ExecutorService`はスレッドプールを管理し、タスクを非同期に実行するためのインターフェースです。`Future`は非同期処理の結果を表現し、処理の完了を待機したり、結果を取得したりするために使用されます。

**即実行可能なコード (Ready-to-Run)**

```java
import java.util.concurrent.ExecutorService;
import java.util.concurrent.Executors;
import java.util.concurrent.Future;
import java.util.concurrent.Callable;
import java.util.concurrent.ExecutionException;

public class AsyncExample {

    public static void main(String[] args) {
        // スレッドプールを作成
        ExecutorService executor = Executors.newFixedThreadPool(2);

        // Callableインターフェースを実装したタスクを定義
        Callable<String> task = () -> {
            System.out.println("Task started in thread: " + Thread.currentThread().getName());
            Thread.sleep(2000); // 重い処理をシミュレート
            return "Task completed!";
        };

        // タスクを非同期に実行
        Future<String> future = executor.submit(task);

        System.out.println("Main thread continues to execute...");

        try {
            // タスクの結果を待機（最大5秒）
            String result = future.get(); // 必要に応じてタイムアウトを設定可能: future.get(5, TimeUnit.SECONDS);
            System.out.println("Result: " + result);
        } catch (InterruptedException | ExecutionException e) {
            e.printStackTrace();
        } finally {
            // ExecutorServiceをシャットダウン
            executor.shutdown();
        }
    }
}
```

**解説:**

*   `Executors.newFixedThreadPool(2)`: 2つのスレッドを持つ固定サイズのスレッドプールを作成します。
*   `Callable`: 結果を返すことができる`Runnable`に似たインターフェースです。
*   `future.get()`: 非同期処理の結果を取得するために待機します。`InterruptedException`や`ExecutionException`が発生する可能性があるため、try-catchブロックで囲む必要があります。
*   `executor.shutdown()`: スレッドプールのリソースを解放します。

**バージョン・アップデート情報:**

*   Java 5: `ExecutorService`と`Future`が導入されました。
*   Java 8: ラムダ式が導入され、`Callable`の実装が簡潔になりました。

**プロフェッショナルな視点:**

*   **メモリ効率**: スレッドプールは、スレッドの作成と破棄のオーバーヘッドを削減し、リソースを効率的に利用します。スレッドプールのサイズを適切に設定することが重要です。
*   **スレッドセーフ**: `ExecutorService`自体はスレッドセーフですが、タスク内で共有リソースにアクセスする場合は、適切な同期化メカニズム（`synchronized`、`Lock`など）を使用する必要があります。
*   **例外処理**: `future.get()`で例外が発生する可能性があるため、適切に処理する必要があります。

### 2.2. `CompletableFuture` (Java 8以降)

`CompletableFuture`は、より柔軟で強力な非同期処理APIを提供します。処理の連鎖、エラーハンドリング、完了時の処理などを容易に記述できます。

**即実行可能なコード (Ready-to-Run)**

```java
import java.util.concurrent.CompletableFuture;
import java.util.concurrent.ExecutionException;

public class CompletableFutureExample {

    public static void main(String[] args) {
        // 非同期タスクを作成
        CompletableFuture<String> future = CompletableFuture.supplyAsync(() -> {
            System.out.println("Task started in thread: " + Thread.currentThread().getName());
            try {
                Thread.sleep(2000); // 重い処理をシミュレート
            } catch (InterruptedException e) {
                e.printStackTrace();
            }
            return "Task completed!";
        });

        System.out.println("Main thread continues to execute...");

        // タスク完了後の処理を定義
        CompletableFuture<String> resultFuture = future.thenApply(result -> {
            System.out.println("Result processing in thread: " + Thread.currentThread().getName());
            return "Result: " + result;
        });

        try {
            // 結果を取得
            String result = resultFuture.get();
            System.out.println(result);
        } catch (InterruptedException | ExecutionException e) {
            e.printStackTrace();
        }
    }
}
```

**解説:**

*   `CompletableFuture.supplyAsync()`: 非同期に値を生成するタスクを作成します。
*   `future.thenApply()`: 前のタスクが完了した後に実行される処理を定義します。
*   `thenApply` は `Function` を引数に取り、前のタスクの結果を引数として処理を行うことができます。

**バージョン・アップデート情報:**

*   Java 8: `CompletableFuture`が導入されました。
*   Java 9以降: さまざまな改善が加えられています。

**プロフェッショナルな視点:**

*   **エラーハンドリング**: `exceptionally()`メソッドを使用して、例外が発生した場合の処理を定義できます。
*   **並列処理**: `thenCombine()`メソッドを使用して、複数の`CompletableFuture`を並列に処理し、結果を結合できます。
*   **キャンセル**: `cancel()`メソッドを使用して、タスクをキャンセルできます。

## 3. C#における非同期処理

### 3.1. `async`と`await`

C#では、`async`と`await`キーワードを使用して、非同期処理を簡単に記述できます。

**即実行可能なコード (Ready-to-Run)**

```csharp
using System;
using System.Threading.Tasks;

public class AsyncExample
{
    public static async Task Main(string[] args)
    {
        Console.WriteLine("Main thread started.");

        // 非同期タスクを実行
        string result = await DoSomethingAsync();

        Console.WriteLine("Result: " + result);

        Console.WriteLine("Main thread completed.");
    }

    // 非同期メソッド
    public static async Task<string> DoSomethingAsync()
    {
        Console.WriteLine("Task started in thread: " + System.Threading.Thread.CurrentThread.ManagedThreadId);
        await Task.Delay(2000); // 重い処理をシミュレート
        return "Task completed!";
    }
}
```

**解説:**

*   `async`: メソッドが非同期操作を含むことを示します。
*   `await`: 非同期操作の完了を待機します。`await`キーワードを使用すると、メソッドの実行が一時停止し、非同期操作が完了するまで待機します。
*   `Task.Delay()`: 指定された時間だけ待機する非同期操作です。

**バージョン・アップデート情報:**

*   C# 5.0: `async`と`await`キーワードが導入されました。
*   C# 7.0以降: 戻り値の型として`ValueTask`がサポートされ、パフォーマンスが向上しました。

**プロフェッショナルな視点:**

*   **UIスレッド**: UIアプリケーションでは、UIスレッドで`await`を使用すると、UIがフリーズするのを防ぐことができます。
*   **例外処理**: 非同期メソッド内で例外が発生した場合、`await`を使用している箇所で`try-catch`ブロックでキャッチする必要があります。
*   **ConfigureAwait(false)**: `await`の後、どのスレッドで処理を継続するかを制御できます。ライブラリコードでは、`ConfigureAwait(false)`を使用することで、デッドロックを回避できます。

### 3.2. `Task.Run`

`Task.Run`メソッドを使用すると、CPUバウンドな処理をバックグラウンドスレッドで実行できます。

**即実行可能なコード (Ready-to-Run)**

```csharp
using System;
using System.Threading.Tasks;

public class TaskRunExample
{
    public static async Task Main(string[] args)
    {
        Console.WriteLine("Main thread started.");

        // CPUバウンドな処理をバックグラウンドスレッドで実行
        string result = await Task.Run(() =>
        {
            Console.WriteLine("Task started in thread: " + System.Threading.Thread.CurrentThread.ManagedThreadId);
            // 重い処理
            System.Threading.Thread.Sleep(2000);
            return "Task completed!";
        });

        Console.WriteLine("Result: " + result);

        Console.WriteLine("Main thread completed.");
    }
}
```

**解説:**

*   `Task.Run()`: 新しいタスクをスレッドプールで実行します。
*   `ラムダ式`: `Task.Run()`に渡す処理をラムダ式で記述します。

**プロフェッショナルな視点:**

*   **CPUバウンドな処理**: `Task.Run()`は、CPUを大量に使用する処理に適しています。
*   **I/Oバウンドな処理**: I/Oバウンドな処理（ネットワーク通信、ファイルI/Oなど）には、`Task.Run()`ではなく、非同期I/O API（`Stream.ReadAsync()`など）を使用する方が効率的です。
