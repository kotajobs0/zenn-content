# 【Wiki】文字列操作 (Java/C# 実装リファレンス)

このWikiでは、JavaとC#における文字列操作の基本的なテクニックと、パフォーマンス、スレッドセーフティに関する考慮事項について解説します。

## 1. 文字列の作成と初期化

### Java

```java
// 文字列リテラルで作成
String str1 = "Hello, World!";

// Stringコンストラクタで作成
String str2 = new String("Hello, World!"); // 非推奨: 文字列リテラルの方が効率的

// 空文字列
String emptyStr = ""; // または String emptyStr = new String();
```

**バージョン・アップデート情報:**

*   Java 9以降では、Stringクラスの内部表現が`char[]`から`byte[]`に変更されました。これにより、Latin-1文字のみを含む文字列のメモリ使用量が削減されます。

**解説:**

*   文字列リテラルは文字列プールに格納され、同じ内容の文字列リテラルは同じオブジェクトを共有します。`new String()`で作成すると、常に新しいオブジェクトが生成されます。
*   メモリ効率を考慮すると、文字列リテラルを使用することを推奨します。

### C#

```csharp
// 文字列リテラルで作成
string str1 = "Hello, World!";

// Stringコンストラクタで作成
string str2 = new string("Hello, World!"); // 非推奨: 文字列リテラルの方が効率的

// 空文字列
string emptyStr = ""; // または string.Empty;
```

**バージョン・アップデート情報:**

*   C# 6.0以降では、文字列補完（String Interpolation）が利用可能になり、より簡潔な文字列フォーマットが可能です。

**解説:**

*   C#でもJavaと同様に、文字列リテラルは文字列プールに格納されます。
*   `string.Empty`は空文字列を表す推奨される方法です。
*   C#の文字列はimmutable（不変）です。

## 2. 文字列の連結

### Java

```java
// + 演算子
String str1 = "Hello";
String str2 = "World";
String result = str1 + ", " + str2 + "!";

// StringBuilder
StringBuilder sb = new StringBuilder();
sb.append("Hello");
sb.append(", ");
sb.append("World");
sb.append("!");
String result2 = sb.toString();
```

**解説:**

*   `+`演算子による文字列連結は、内部的に`StringBuilder`を使用するため、ループ内など大量の連結を行う場合は`StringBuilder`を明示的に使用する方が効率的です。
*   Javaの`String`はimmutableなので、`+`演算子を使うたびに新しい`String`オブジェクトが生成されます。

**スレッドセーフ:**

*   `StringBuilder`はスレッドセーフではありません。マルチスレッド環境で使用する場合は`StringBuffer`を使用する必要があります。ただし、`StringBuffer`は`StringBuilder`よりもパフォーマンスが劣ります。シングルスレッド環境であれば`StringBuilder`が推奨されます。

### C#

```csharp
// + 演算子
string str1 = "Hello";
string str2 = "World";
string result = str1 + ", " + str2 + "!";

// StringBuilder
using System.Text;

StringBuilder sb = new StringBuilder();
sb.Append("Hello");
sb.Append(", ");
sb.Append("World");
sb.Append("!");
string result2 = sb.ToString();

// 文字列補完 (C# 6.0以降)
string name = "World";
string result3 = $"Hello, {name}!";
```

**解説:**

*   C#でもJavaと同様に、`+`演算子による文字列連結は、内部的に`StringBuilder`を使用します。大量の連結を行う場合は`StringBuilder`を明示的に使用する方が効率的です。
*   C#の`String`もimmutableです。
*   文字列補完は、`StringBuilder`を使用するよりもさらに簡潔に文字列をフォーマットできます。

**スレッドセーフ:**

*   C#の`StringBuilder`はスレッドセーフではありません。マルチスレッド環境で使用する場合は、ロック機構などを使用して排他制御を行う必要があります。

## 3. 文字列の比較

### Java

```java
String str1 = "Hello";
String str2 = "hello";

// == 演算子 (オブジェクトの比較)
boolean isEqualObject = (str1 == str2); // false (通常は異なるオブジェクト)

// equals()メソッド (内容の比較)
boolean isEqualContent = str1.equals(str2); // false
boolean isEqualContentIgnoreCase = str1.equalsIgnoreCase(str2); // true
```

**解説:**

*   `==`演算子は、オブジェクトの参照を比較します。文字列の内容を比較するには、必ず`equals()`メソッドを使用してください。
*   大文字小文字を区別せずに比較する場合は、`equalsIgnoreCase()`メソッドを使用します。

### C#

```csharp
string str1 = "Hello";
string str2 = "hello";

// == 演算子 (内容の比較)
bool isEqual = (str1 == str2); // false

// String.Equals()メソッド (内容の比較)
bool isEqual2 = string.Equals(str1, str2); // false
bool isEqualIgnoreCase = string.Equals(str1, str2, StringComparison.OrdinalIgnoreCase); // true
```

**解説:**

*   C#では、`==`演算子は文字列の内容を比較します。ただし、参照型であるため、常に内容が比較されるわけではありません。
*   明示的に内容を比較するには、`String.Equals()`メソッドを使用することを推奨します。
*   大文字小文字を区別せずに比較する場合は、`StringComparison.OrdinalIgnoreCase`を指定します。

## 4. 文字列の検索

### Java

```java
String str = "Hello, World!";

// 文字列の検索
int index = str.indexOf("World"); // 7
int lastIndex = str.lastIndexOf("o"); // 8

// 部分文字列のチェック
boolean contains = str.contains("World"); // true
```

### C#

```csharp
string str = "Hello, World!";

// 文字列の検索
int index = str.IndexOf("World"); // 7
int lastIndex = str.LastIndexOf("o"); // 8

// 部分文字列のチェック
bool contains = str.Contains("World"); // true
```

## 5. 文字列の置換

### Java

```java
String str = "Hello, World!";
String replacedStr = str.replace("World", "Java"); // "Hello, Java!"
String replacedAllStr = str.replaceAll("o", "x"); // "Hellx, Wxrld!" (正規表現)
String replacedFirstStr = str.replaceFirst("o", "x"); // "Hellx, World!" (正規表現)
```

**解説:**

*   `replace()`メソッドは、文字列内のすべての指定された文字列を置換します。
*   `replaceAll()`メソッドは、正規表現を使用して文字列を置換します。
*   `replaceFirst()`メソッドは、正規表現に最初に一致する文字列を置換します。
*   正規表現を使用する場合は、パフォーマンスに注意してください。

### C#

```csharp
string str = "Hello, World!";
string replacedStr = str.Replace("World", "C#"); // "Hello, C#!"
```

**解説:**

*   C#の`Replace()`メソッドは、文字列内のすべての指定された文字列を置換します。
*   C#にはJavaの`replaceAll()`や`replaceFirst()`に相当するメソッドは標準ではありませんが、`Regex`クラスを使用して同様の処理を行うことができます。

## 6. 文字列の分割

### Java

```java
String str = "apple,banana,orange";
String[] parts = str.split(","); // {"apple", "banana", "orange"}
```

### C#

```csharp
string str = "apple,banana,orange";
string[] parts = str.Split(','); // {"apple", "banana", "orange"}
```

## 7. 文字列のフォーマット

### Java

```java
String name = "Alice";
int age = 30;
String formattedStr = String.format("Name: %s, Age: %d", name, age); // "Name: Alice, Age: 30"
```

### C#

```csharp
string name = "Alice";
int age = 30;
string formattedStr = string.Format("Name: {0}, Age: {1}", name, age); // "Name: Alice, Age: 30"

// 文字列補完 (C# 6.0以降)
string formattedStr2 = $"Name: {name}, Age: {age}"; // "Name: Alice, Age: 30"
```

## 8. 文字列のトリム (Trim)

### Java

```java
String str = "   Hello, World!   ";
String trimmedStr = str.trim(); // "Hello, World!"
```

### C#

```csharp
string str = "   Hello, World!   ";
string trimmedStr = str.Trim(); // "Hello, World!"
```
