# Zenn Contents Repository (Automated)

このリポジトリは、GitHub Actions と AI（Gemini / Claude）を活用して、技術知見を Zenn へ自動投稿する仕組みを構築し、蓄積するためのものです。

## 🎯 運用の目的（ゴール）
**「若手社員がこの記事を見て、エンジニアとしての理解や知識を体系的に蓄積できること」**
単なる技術情報の要約ではなく、シニアエンジニアの思考プロセスを可視化した「生きた社内Wiki」を目指します。

---

## 🚀 主要な投稿テーマ

### 1. AIとの対話プロセスの定点観測 × 言語習得
若手が直面する「実装のお作法（デザインパターンや型安全な書き方）」の習得を支援します。

* **リファクタリングの対話ログ**
    * **内容:** 「動くが読みにくいコード」を Gemini/Claude で「保守性の高いモダンなコード（Java 21 / C# 12等）」へ修正する過程を公開。
    * **ポイント:** AIの提案理由を深掘りし、「より良い書き方」への思考プロセスを共有。
* **エラー解消デバッグ・ドキュメント**
    * **内容:** `NullPointerException` や `async/await` 等の典型的なエラーログと、AIによる解決プロセスの記事化。

### 2. 「動く社内Wiki」としての活用
従来の静的なWikiを超え、エンジニアが実際に活用できる資産とします。

* **即実行可能なコード:** Markdown 形式により、VS Code 等へそのままコピペして動作確認が可能。
* **バージョンの明確化:** Java 17 から 21 への移行など、言語アップデートに伴う変更点を履歴として管理。
* **技術ブランディング:** 教育に熱心なチームであることを社内外へアピール。

### 3. Java / C# 特化型ナレッジの蓄積
AIが得意とする静的型付け言語の厳密さを活かしたコンテンツを生成します。

| 蓄積テーマ | 具体的な内容例 | 若手へのメリット |
| :--- | :--- | :--- |
| **モダン書き換え辞典** | Javaの `for文` → `Stream API` への書き換え比較。 | 古いコードをモダンにする技術の習得。 |
| **ライブラリ比較** | `Lombok` や `AutoMapper` 等の定番ツールの活用法。 | 開発現場での即戦力となる知識。 |
| **型安全の極意** | C# の `Nullable` や `record` 型の活用法。 | バグの少ない堅牢なコードを書く習慣。 |
| **ユニットテスト生成** | `JUnit` や `xUnit` のテストコード自動生成と検証。 | テストへの心理的ハードルを下げ、品質意識を向上。 |
